# 읽걷쓰AI 기반 학생 평가와 학습코칭 — 연수 다시 보기 (2026. 10. 22.)

연수 때 Firebase 실시간 앱(rww-ai-1022)으로 진행한 7단계 활동을 정적 사이트로 옮긴 것.

- 고른 것(기분·퀴즈·자리배치 체험)은 각자 브라우저(localStorage)에만 저장된다.
- 「모두의 결과」는 연수 당일 결과에서 이름·학교·글을 빼고 고른 값만 담은 `js/results.js`.
- 빼 둔 것: 계산왕 대회(실제 대회 앱), 1·2단원 구글 사이트와 4·5단원 기하 체험관(실제 수업 사이트), 강사 대시보드, 역사 논술형 답안지 PDF.
- 자리배치 체험(`seat/`)은 AI 가상 학생 150명, Firebase 대신 브라우저 저장소를 쓴다.
- 원본 앱: `../연수앱(Firebase)/` (public 폴더). 당일 집계 다시 받기: 그 폴더에서 `node tools/agg_session.js rehearsal-16 agg.json`
